## 2026-07-10 - Secure let SDK config file creation permissions | Vulnerability: Insecure file creation with potential TOCTOU race condition | Learning: Using Path.write_text() creates files with default permissions before changing them with os.chmod, which creates a TOCTOU race condition exposing sensitive configurations. | Prevention: Always use os.open() with O_CREAT and explicitly specify the desired mode (e.g. 0o600) when creating sensitive files to avoid race conditions.
