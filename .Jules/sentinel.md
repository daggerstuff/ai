## 2024-05-20 - Missing Default Fallback Validation | Vulnerability: Missing Default Fallback Validation / Configuration | Learning: Developers often rely on `os.environ` or `os.environ.get()` for retrieving secrets like `AUTH_SECRET_KEY` without checking if the key actually exists and has a non-empty value. This can cause the application to initialize with insecure defaults or throw unhandled KeyErrors. | Prevention: Always validate critical configuration values immediately upon loading, raising explicit ValueErrors if they are missing or insecure, rather than failing silently or with cryptic errors deeper in the code.
